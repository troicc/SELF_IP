# 坐一会儿再走

一个**刻意做简单**的双人手绘对话 IP：阿迟把没说出口的话说出来，周叔帮他把问题拆成一句现实里能说出口的话。

这个仓库现在只做三件事：

1. 用五页讲完一个具体的小故事；
2. 复用四张固定半身镜头，不为每一页重新设计复杂动作；
3. 用本地 SVG 排版正文，不再把大块半透明白框压在插画上。

原来的 108 张基准图、三画风竞赛、逐物件连续性、七页场景、FFmpeg 裁切落位和多阶段 postflight 已从项目中移除。插画是内容的载体，不是电影分镜。

## 一条命令

```bash
python3 scripts/build.py episodes/EP-001.json
```

输出：

```text
build/EP-001/
├── prompts.jsonl      # 四种固定镜头的生图请求
├── cards/             # 五张 1080×1440 SVG 卡片
├── caption.txt        # 发布文案
└── manifest.json
```

没有正式插画时，卡片会明确显示“插画占位”，只用于检查排版，不会伪装成成品。

[查看五页版式证明](examples/EP-001-layout-proof/README.md)

## 四张图就够了

先生成并人工挑选四张长期复用的图：

```text
assets/plates/quiet.png
assets/plates/achi-talk.png
assets/plates/zhoushu-talk.png
assets/plates/together.png
```

四张图均为 4:3、双人胸像或半身：

- `quiet`：阿迟低头，周叔听；
- `achi-talk`：阿迟是视觉焦点；
- `zhoushu-talk`：周叔是视觉焦点；
- `together`：谈完后的安静同框。

不画完整房间、桌椅、餐具、腿脚、精细手指、手机界面或多人走位。情绪只靠目光、嘴角、头部角度和两人的距离表达。

## 五页内容结构

1. **钩子**：一个具体问题；
2. **事实**：发生了什么；
3. **感受**：真正介意的是什么；
4. **表达**：一句现实里可以直接发送或说出口的话；
5. **结果**：人物做了什么，再落一层小道理。

一篇最多两个角色、一个事实、一个重要句子。第四页必须给出具体表达，第五页必须交代行动，不能只留一句作者金句。

示例选题：

> 面都坨了，还要回“没事”吗？

示例中的关键表达：

> 下次有变，能在我出门前告诉我吗？

落点：

> 体谅别人，不必先省掉自己。

## 新建一篇

复制示例，只改文字和所用镜头：

```bash
cp episodes/EP-001.json episodes/EP-002.json
python3 scripts/build.py episodes/EP-002.json
```

不要为新选题修改角色造型、画风或新增长篇场景说明。

## 验证

```bash
make test
```

测试会检查：

- 必须正好五页；
- 只使用四种固定镜头；
- 每页最多两个文本块；
- 不出现旧版半透明大白框和 `01/07` 页码；
- 生图请求明确禁止家具、全身、精细手部、复杂手势和第三个人；
- 文案不靠心理标签和空泛术语冒充洞察。

核心规则见 [`ip/IP_BIBLE.md`](ip/IP_BIBLE.md)，视觉合同见 [`visual/plates.json`](visual/plates.json)。
