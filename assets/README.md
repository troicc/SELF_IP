# 固定镜头资产

`assets/plates/` 保存四张长期复用的透明 PNG：

- `quiet.png`
- `achi-talk.png`
- `zhoushu-talk.png`
- `together.png`

推荐 1080×1440 或更高分辨率、透明背景。人物只画胸像或半身，底部可柔和淡出；不要让图像模型生成文字、气泡、家具、完整手部动作或第三个人。

透明背景很重要：构建器会先画气泡尾线，再叠人物，尾线因此能自然藏到人物轮廓后面。若使用不透明整页图片，气泡尾线会被整张图片遮住。

`assets/references/` 仍负责角色身份。`visual/plates.json` 负责画风、人物位置、嘴边锚点和气泡槽位。字体文件不放入仓库。
